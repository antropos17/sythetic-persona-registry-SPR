# Fictional passport portraits

These eight headshots were generated for the SPR demonstration on 19 October 2026 with the built-in image generation tool. Each depicts a fictional adult. They are illustrative assets, not photographs of applicants or evidence of identity, consent, rights, or an examiner's review. Do not present them as official identity documents.

The selected fictional full-length image for each persona in [`../full-body/`](../full-body/) was used as an identity reference to generate a matching front-facing head-and-shoulders portrait. The common brief requested a neutral closed-mouth expression, direct eye contact, a matte light gray background, diffuse light, ordinary clothing, and photographic skin and hair texture. It excluded text, watermarks, document borders, flags, glamour retouching, dramatic lighting, and CGI styling. One generation call was made for each final headshot. The selected PNG output was encoded as a quality-90 JPEG for the site without retouching or compositing.
