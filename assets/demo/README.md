# Private-case illustration

These static assets were authored with Benji Taylor's Stageshow `static-card` example and kit, adapted to SPR's colours and truthful private-case workflow. The MIT notice is included in this directory. Editable adaptation and the rehearsal are in `docs/demo/`.

`process-desktop.png` is an 800 × 600 export of the 400 × 300 stage. `process-compact.png` is a 716 × 600 export of the distinct 358 × 300 compact composition. These are fictional explanatory illustrations, not screenshots or real case records.
