# Схема паспорта: заметки к v0.2

Файл `persona-passport.v0.1.json` — скелет схемы (Identity Root + Model Bill of Materials). Ниже — правки, согласованные для v0.2.

## Ключевые правила v0.1 (сохранить)

- `null` — поле ещё не заполнено; `"unknown"` — искали, но не нашли; `false` — проверено и неверно.
- `unknown_upstream` есть у каждого компонента, а не только у базовой модели.
- Лицензия хранится как снимок: `license_url`, `license_text_sha256`, дата загрузки.
- `evidence_level` никогда не повышается автоматически.

## Правки для v0.2

1. **Битые ссылки.** `reference_assets.origin.generation_event_id` и `training.dataset_ids` ссылаются на секции, которых нет. Добавить пустые массивы `generation_events[]` и `datasets[]`.
2. **Онлайн-сервисы без файлов.** Новый `component_type: "hosted_service"` без `artifact`, но с `terms_snapshot` (URL, SHA-256 текста условий, дата), `subscription_tier`, `output_rights_status`. Нужно для Suno, Kling, генераторов изображений.
3. **Риск голоса.** Добавить в `unresolved_risks` риск категории `voice_rights` с серьёзностью high: голос сделан на hosted-сервисе, права зависят от тарифа, происхождение обучающих данных сервиса неизвестно.
4. **Собственная LoRA.** `transfer_allowed` → `"allowed_with_transfer_agreement"` вместо `"case_by_case"`.
5. **Порядок заполнения.** Пункт 0 — инвентаризация hosted-сервисов, затем локальные файлы: имя → SHA-256 → источник → снимок лицензии → родитель → эталонные изображения. Всё, что не установлено, уходит в `unresolved_risks`.

## Уровни доказательности

| Уровень | Значение |
|---|---|
| Declared | Владелец сделал декларацию |
| Evidence-backed | Приложены источники, лицензии, хэши, согласия |
| Reviewed | Материалы проверил независимый специалист |
| Controlled creation | Персона создана в наблюдаемом конвейере, каждый шаг записан |
| Флаг Unknown upstream | Ставится рядом с любым уровнем, если происхождение базовой модели нельзя подтвердить |

Формулировка отчёта вместо «реальных людей не использовали»: «В проверенных материалах не найдено свидетельств использования изображений реальных людей без разрешения. Ограничения проверки перечислены отдельно».

## Цветовые нотисы на сайте

| Нотис | Статус паспорта | Совет |
|---|---|---|
| Green | Valid | Можно работать |
| Yellow | Under review | Дождаться решения |
| Orange | Suspended | Не запускать кампании |
| Red | Revoked | Не использовать, сообщать о копиях |
